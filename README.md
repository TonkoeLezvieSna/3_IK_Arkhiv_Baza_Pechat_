# 3
2 часть программы для автоматического формирования судебно-биологического заключения

1.1.	Замена кодировки UTF-8 на Windows-1251, оптимизация по избыточным операциям и задержкам (Claude).

1.2.	Добавлено автозаполнение шаблона VBA из Карты.

1.3.	Создано корректное название файла.

1.4.	Созданы замены родственников с родительного падежа на именительный.

1.5.	Сохранение в архив перемещено в конец главной функции.

1.6.	Добавлено сохранение файла xml в базу.

1.7.	Добавлен блок try-except вокруг основной функции для отображения ошибок (отменён в этом виде).

1.8.	Добавлен выбор шаблона Word при выборе карты личной/родственников, встроена система отображения ошибок.

1.9.	Добавлен выбор при наличии нескольких файлов в папке с рабочими материалами и нескольких объектов в файле.

1.10.	Добавлен выбор папки сохранения в зависимости от того, какой шаблон был выбран - личный или родственников.

1.11.	Исправлено обращение к файлу "Карта" на обращение к любому файлу Excel в той же директории.

1.12.	При конвертировании txt в xml добавлено распознавание заголовков на русском языке.

1.13.	Убрано дублирование путей (родственники/личный).

1.14.	Добавлена функция печати.

1.15.	Добавлена сортировка по порядку нескольких профилей из файла txt при выборе в консоли.

1.16.	Изменены метки для замены изображений, убран суффикс -25 для xml.

1.17.	Добавлено обращение к макросу ИК-2, убрана необходимость в строке для ИК - они выбираются в соответствии с видом шаблона заключения.

1.18.	Добавлено текстовое сообщение в конце работы программы о необходимости совершить действия; выделены особые сценарии для определённых видов заключений в строке 1 Карты.

1.19.	При наличии в ячейке ТР прямого или обратного слеша в названии файла он заменяется на дефис.

1.20.	Текстовое сообщение в начале работы программы о необходимости проверить ФИО в именительном падеже.
