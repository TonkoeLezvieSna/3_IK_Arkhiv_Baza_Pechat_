1.9.	Добавлен выбор при наличии нескольких файлов в папке с рабочими материалами и нескольких объектов в файле.

1.10.	Добавлен выбор папки сохранения в зависимости от того, какой шаблон был выбран - личный или родственников.

1.11.	Исправлено обращение к файлу "Карта" на обращение к любому файлу Excel в той же директории.

1.12.	При конвертировании txt в xml добавлено распознавание заголовков на русском языке.

1.13.	Убрано дублирование путей (родственники/личный).

1.14.	Добавлена функция печати.

1.15.	Добавлена сортировка по порядку нескольких профилей из файла txt при выборе в консоли.

1.16.	Изменены метки для замены изображений, убран суффикс -25 для xml.

1.17.	Добавлено обращение к макросу ИК-2, убрана необходимость в строке для ИК - они выбираются в соответствии с видом шаблона заключения.

1.18.	Добавлено текстовое сообщение в конце работы программы о необходимости совершить действия; выделены особые сценарии для определённых видов заключений в строке 1 Карты.

1.20.	Текстовое сообщение в начале работы программы о необходимости проверить ФИО в именительном падеже.

1.21. Добавлено временное сохранение файлов Word и Excel в папке результатов и одновременное перемещение в финальную папку.

1.22.	Реализованы механизмы работы с образцами и костями без результата - создание результирующего файла Word, отдельная работа с исходным файлом Word; перемещение в архив осуществляется минимально, без использования shutil.copy.

1.23.	Создан механизм распределения результатов заключений из ЭКЦ, в том числе обработки карты с названием листа "ИКЛ".

1.24.	Добавлено отправление заключения в папку для ВСК.

1.25.	Автозаполнение сопроводительного листа для ВСК.

1.26.	Введено убирание лишних пробелов при взятии из Карты, реализована печать сопроводительных листов.

1.27.	Исправлена ошибка, когда после изменения Карты во время работы программы при выведение предупреждения о ФИО значения в программе были уже прочитаны и использовались старые.

1.28.	При создании сопроводительных листов разделение по обращению к шаблону родственников и прямой идентификации, при печати - формулирование вопроса в зависимости от того, распечатывается ли заключение или сопроводительный лист; изменён словарь по замене метки РОД.

1.29.	Добавлена функция автозаполнения и распечатывания конверта.

1.30.	Создана функция обработки УТдГ, разделены пути исполнения УТдГ и ИК-2.

1.33.	Удаление из шаблона меток, которые не встречаются в Карте.

1.34.	Создано предупреждение, если в Карте нет индекса; убрано предупреждение о проверке ФИО в именительном падеже.

1.35.	Созданы разные виды предупреждений для образцов, костей и ЭКЦ.

1.36.	Отдельный блок для финальной обработки для "ЭКЦ_образец_нет результата".

1.38.	Анализируется до 4 аллелей, таблица заполняется всеми аллелями, в файл xml вносятся все аллели.

1.39.	Встроен декоратор из 2 части для обработки ошибки win32com.

1.40.	Добавлена возможность работы с шаблонами "ЭКЦ_образец_".

1.41.	Улучшено формирование заголовков файлов и заполнение ИКЛ, устранено формирование None, очищение от лишних пробелов при удалении меток.

1.42.	Создана отдельная логика для печати документов ЭКЦ.

1.42.1.	К ФИО подэкспертного и пропавшего в Универсальной карте добавляется дата рождения.
